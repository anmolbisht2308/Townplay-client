# Townplay client

Next.js web app (public site, player account, owner dashboard, admin). See `CLAUDE.md` and `docs/PLAN.md`.

```
pnpm install
cp apps/web/.env.example apps/web/.env   # API_URL=http://localhost:4000
pnpm dev                                 # http://localhost:3000 (api from Townlplay-server)
```
